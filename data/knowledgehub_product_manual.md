# KnowledgeHub 企业知识库产品手册

## 一、产品定位

KnowledgeHub 是面向企业内部的知识检索与问答平台，将分散在制度文档、产品手册、项目复盘中的非结构化文本转为可检索的向量知识，并通过大语言模型生成带来源引用的回答。系统不生成知识库中不存在的结论，检索证据不足时明确拒答。

产品当前版本 v1.4，由产品部维护，研发部负责实现，部署形态为私有化部署。

## 二、版本与功能矩阵

| 版本 | 发布时间 | 主要能力 |
|---|---|---|
| v1.0 | 2026-03-15 | 多格式文档加载、文本切分、Chroma 向量入库、基础相似度检索 |
| v1.1 | 2026-04-20 | RAG 问答链、答案来源引用、证据不足拒答 |
| v1.2 | 2026-05-18 | Metadata 条件过滤、混合检索、Reranker 重排序 |
| v1.3 | 2026-06-10 | Agent 工具调用、多步骤任务、会话历史持久化 |
| v1.4 | 2026-06-30 | FastAPI 服务、流式输出、日志与异常处理、按部门权限隔离 |

## 三、支持的文档格式与规格

- 支持格式：PDF、Word（.docx）、TXT、Markdown（.md）四种。
- 单文件大小上限 20 MB，单次批量上传不超过 50 个文件。
- 文本编码统一为 UTF-8；扫描件 PDF 若不含文本层，需先经 OCR 处理再上传。
- 每个文档在入库时写入六个元数据字段：source、title、department、doc_type、version、created_at。
- 文档更新采用「同 doc_id 覆盖」策略，旧版本向量会被删除后重建索引。

## 四、核心能力参数

| 能力 | 默认值 | 说明 |
|---|---|---|
| 切分块大小 | 500 字符 | 重叠 80 字符，优先按段落与句号切分 |
| 检索返回数 | top_k = 4 | 可在请求中覆盖，最大 10 |
| 相似度阈值 | 0.35 | 低于阈值视为证据不足，触发拒答 |
| Agent 最大迭代 | 6 次 | 防止工具循环调用 |
| 保留历史轮数 | 10 轮 | 超出后按时间裁剪 |
| 服务端口 | 8000 | 接口前缀 /api/v1，限流 30 次/分钟 |

## 五、部署要求

- Python 3.11 及以上，建议使用独立虚拟环境 .venv。
- 向量库 Chroma 持久化目录 ./database/chroma，需保证磁盘可写并纳入备份。
- Embedding 模型默认 BAAI/bge-small-zh-v1.5，可在 CPU 上运行；生产环境建议使用 GPU。
- 大语言模型通过 OpenAI 兼容 API 接入，密钥由环境变量注入，禁止写入代码或配置文件。
- 最低运行内存 4 GB，收录十万级文本块建议 8 GB 以上。

## 六、内部结算与授权

内部部门按季度结算，基础额度含 5 万次问答调用，超出部分按量计费。对外输出的材料（如客户 FAQ）需标记为「对外可发布」，标记为「内部机密」的文档禁止进入对外检索通道。

## 七、路线图

2026 年第三季度重点为检索效果评估体系与多路召回，第四季度计划支持表格问答与文档自动摘要。接口细节见 ENG-2026-008《KnowledgeHub API 接口说明》。
